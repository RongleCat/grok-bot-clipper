# 区域截图与侧栏补充信息

按用户确认的方向执行：全部界面图标使用本地打包的 Lucide；原生桌面头像引擎保持原样；BOT 列表三列；白灰界面、圆角面板、正文 14–15px、辅助文字至少 13px。

区域截图先注入独立 Shadow DOM 框选层，拖动确认、Esc 取消，移除遮罩后截图，按截图实际像素与视口比例裁剪。校验当前标签页和请求账户，禁止将取消当作全屏截图。

设置增加补充信息位置：侧栏（默认）或独立窗口。侧栏承载与窗口相同的网页组件，通过草稿通知切换；在操作手势内预先打开侧栏，再采集材料，避免异步采集后丢失手势。截图选区阶段不打开侧栏，避免改变视口；选区完成的手势中打开侧栏也会改变视口，因此先完成截图再显示可点击的继续按钮，由新手势打开侧栏。

布局：紧凑 BOT 选择、说明输入区、任务选择与附件入口、材料预览、固定发送区；侧栏内只保留一个主滚动区域。截图编辑仍保留裁剪、打码和箭头。

验证：区域正向/反向拖动、取消、视口变化、Lucide 适配、侧栏/窗口路由、三列与可读字号；运行测试和打包，在 Chrome 中走真实框选与补充界面。
