# Complete extension localization

User scope: prepare Grok Bot Clipper for international users and future Chrome Web Store distribution; localize every extension-owned visible surface, not only the listing. User explicitly requested multiple agents and Grok Build collaboration. Existing instruction to avoid automatic build/release workflows remains.

Architecture: shared t(source, values) module; explicit localization calls at owned UI boundaries and lazy-loaded bundled catalogs; source/material/BOT text is never translated. UI language follows the browser by default, with a persisted manual override. Chrome's supported locale registry has 55 entries. English is the fallback; native metadata uses default_locale en and generated _locales directories. Content scripts request only a safe locale/string payload from background and never change the host page's lang/dir. Extension documents and owned overlays handle RTL. Keep internal protocol/storage identifiers unchanged.

Parallel tasks: main app/settings/drafts/chat/markdown; background/content/social/offscreen/generated envelopes; manifest/build/CSS/coverage audit; root integration/core/catalog generation/validation. Grok Build performs an independent source audit and language catalog translation; translations are machine-assisted and structural checks do not substitute for native-speaker review.

Validation: failing core locale tests, locale aliases/placeholder/document direction/date format; runtime main/share UI switching and user-content isolation; complete catalog and metadata parity; AST audit for untranslated owned source strings; long-label and RTL browser fixtures; full regression and both browser source builds. No Web Store submission or automated packaging is included.

Completed validation (2026-10-18, version 0.4.0): 55 complete catalogs with 386 keys each; source/catalog/placeholder/metadata audit passed; 214 tests passed; Chrome and Firefox source builds passed and each contains all 55 native locale catalogs. Isolated headless Chrome fixtures checked English, German, French and Arabic layout. Firefox web-ext lint reported 0 errors, 0 notices and 34 static warnings concerning dynamic HTML assignments and third-party code; these are not a claim of store approval. All translations are machine-assisted; English terminology and selected German/French/Spanish entries received an additional editorial pass, not universal native-speaker certification. No automatic packaging or release workflow was added.
