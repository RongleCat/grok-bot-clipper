# Native share spacing and chooser activation follow-up

User evidence: Douyin BOT buttons reach the popup edge, while native rows have parent-level horizontal insets. The reserved friend region leaves a blank area after loading. XHS other-BOT activation appears inert.

Investigation: BOT rows copy only the native row's own padding, losing viewport/ancestor insets. We shrink only the scroll node, leaving fixed-height outer friend wrappers at their original size. The XHS route waits for a network snapshot before mounting any picker and own controls do not protect pointer-down from native popup dismissal.

Plan: add failing regressions with parent-level padding, nested fixed-height friend wrappers and native pointer-down dismissal; derive button/avatar alignment from native element geometry with safe CSS fallback. Isolate above the complete friend-only wrapper and reserve space across its layout chain, retaining/restoring original styles and avoiding cumulative resizing. Protect extension controls' pointer-down and show a cancelable loading chooser immediately before the async XHS snapshot. Validate actual compact frame activation and layout with a real headless fixture, focused/full tests and both browser packages. Do not claim live-site reproduction without the original page or browser access.

Completed in 0.3.6. BOT row padding now follows measured native avatar/button insets (with an unscaled CSS fallback), avatar dimensions and row/button typography use native sizes, and XHS cells avoid inherited native control classes/pointer disabling. The whole friend-only layout chain is measured before any writes; each reserved wrapper is resized together, subsequent native height writes are reconciled without cumulative shrinking, and all original inline styles are restored on cleanup. BOT insertion remains outside native virtual-row coordinates.

Own controls protect pointerdown/mousedown/touchstart from native bubbling dismissal. Choosing another BOT immediately creates a cancelable preparation host, then loads the compact search iframe after metadata capture. A canceled host token cannot be reopened by the old request; errors are shown only in the corresponding preparation host. Extension frame source/origin/request checks remain intact.

Validation: all 169 tests pass. New regressions were observed failing before the fixes, including the separate compatibility mousedown event. Read-only review found no blockers. A real headless Chrome fixture with nested fixed-height wrappers verified matching native/BOT button right edges, constant combined height after a simulated late height reset, and no blank reserved strip (`artifacts/douyin-spacing-0.3.6.png`). A separate XHS-shaped fixture verified early preparation, survival of native dismissal, actual iframe mounting, and working search (`artifacts/xhs-inline-picker-0.3.6.png`). These are local fixtures, not the user's logged-in live sites. Both browser packages build successfully; Firefox lint remains 0 errors, 0 notices and 31 existing warnings.
