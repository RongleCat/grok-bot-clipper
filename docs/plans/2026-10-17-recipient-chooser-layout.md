User requests: replace the oversized hand-drawn plus/circle with a smaller official icon on Douyin and Xiaohongshu; show BOTs reliably in Douyin; put the other-BOT chooser directly after injected BOTs and before native friends.

Confirmed issues: chooser circle is styled text with a border rather than a library icon. Douyin BOT rows use flex-basis:100%, which consumes the full height of a vertical flex list per BOT; inherited native row positioning/height can further hide injected rows. The chooser is appended after the entire recipient list. Prepending rows without resetting a retained scroll position can leave BOTs above the visible viewport.

Plan: add regression assertions for official icon sizing, non-growing vertical rows, native-friend preservation and exact BOT/chooser/friend order. Insert the chooser in the same fragment after BOTs, reset the list to the top on initial insertion, preserve existing lifecycle cleanup, and verify a real vertical-flex fixture visually. Run focused/full tests and Chrome/Firefox package/lint checks.
